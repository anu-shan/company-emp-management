
# PeopleHub – Employee Management Website

## Project Overview

PeopleHub is a simple and responsive employee management website built using HTML, CSS and JavaScript.

It provides a user-friendly interface to explore employee information and contact the company.

## Website Pages

1. **Home** – Introduction to PeopleHub.
2. **Employees** – Displays employee details with search functionality.
3. **Contact** – Displays company contact information and a demo contact form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Features

- Three-page website
- Navigation between pages
- Responsive design
- Employee search functionality
- Contact form demo interaction
